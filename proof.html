5. Offline state — document attribute, cache, staleness

OFFLINE.init() stamps document.documentElement[data-deer-online] at startup. The fixture is read on page load (panel 4), so it sits in the IndexedDB cache. Press Re-render with offline simulation on: the view must come from the cache, carry data-deer-stale, and fire deer-stale.

6. Write queue — refusals never poison the outbox

Consolidation change: a server refusal (4xx) must reject, never queue — replaying an unmodified rejected request can only fail identically and blocks every later write behind it. While offline the same write must queue and resolve null; syncing replays the queue in order.

8. Structured logging — one record shape, one gate, one sink issue 8
