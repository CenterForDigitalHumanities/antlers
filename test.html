DEER 2.0 Test Bench

Scratch page for creating and annotating test entities against devstore.rerum.io via tinydev.rerum.io, using the local /js/ source. Everything made here is tagged ANTLERS_2_0_TEST_AGENT on both the entity (creator) and every annotation (deer-creator), so it can be told apart from the rest of the shared sandbox — the sandbox generator is shared by every app and cannot discriminate.

1. Create a Person

Creates one entity plus one Annotation per dirty input. name is in DEER.PRIMITIVES, so it lands on the entity and as an annotation — that is deliberate here, it reproduces the heterogeneous merge documented in antlers#1.
